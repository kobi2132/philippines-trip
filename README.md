# הטיול לפיליפינים

אפליקציית ווב (PWA) בעברית לשמוליק ואתי לטיול בפיליפינים, 6–26 בנובמבר 2026.
מותקנת במסך הבית של הטלפון, עובדת גם בלי אינטרנט, ומראה בכל יום את מה שחשוב לו: טיסות, מעברים, מלון והמלצות.

## איך זה בנוי

- אתר סטטי (HTML/CSS/JS בלי שלב בנייה), מתפרסם ל-GitHub Pages בכל push ל-`main`.
- **הנתונים האישיים לא נמצאים בריפו.** הם יושבים ב-Firestore, ורק חשבונות הגוגל שברשימת המשתמשים של הטיול יכולים לקרוא אותם (`firebase/firestore.rules`).
- אחרי הכניסה הראשונה הנתונים נשמרים בטלפון, כך שהכל עובד גם בלי קליטה.

| קובץ | תפקיד |
| --- | --- |
| `js/config.js` | הגדרות Firebase ומזהה הטיול |
| `js/backend.js` | כניסה עם גוגל, טעינת הנתונים מ-Firestore |
| `js/trip.js` | חישובים על הנתונים (איזה מלון הלילה, מתי להיות בשדה) |
| `js/views.js` | המסכים |
| `js/map.js` | מפת המסלול |
| `js/main.js` | ניווט בין מסכים, אירועים, מזג אוויר |
| `sw.js` | עבודה בלי אינטרנט |
| `tools/build_preview.py` | בונה קובץ HTML אחד עם הנתונים בפנים, לתצוגה מקדימה (לא לעשות לו commit) |

## תצוגה של יום מסוים

מוסיפים לכתובת `?date=2026-11-14` כדי לראות את האפליקציה כאילו היום 14.11. `?date=real` מחזיר לתאריך האמיתי.

## עדכון הנתונים

נכנסים כמנהל, מידע ← ניהול נתונים, עורכים את ה-JSON ושומרים. ההורים מקבלים את העדכון בפתיחה הבאה.

## סטטוס טיסות והתראות

`notifier/` רץ כל 15 דקות ב-GitHub Actions (`.github/workflows/notifier.yml`) באוקטובר ובנובמבר:

- שולח תזכורות: eTravel יומיים לפני, אריזה יום לפני, בוקר טוב בכל יום בטיול, וביום טיסה מתי להיות בשדה.
- בודק את מצב הטיסות ב-AeroDataBox ושולח התראה על ביטול, שינוי שעה או שער.
- כותב את מצב הטיסות ל-Firestore, והאפליקציה מציגה אותו בכרטיס הטיסה.

צריך שני secrets בריפו (Settings ← Secrets and variables ← Actions):

| Secret | מה זה |
| --- | --- |
| `FIREBASE_SERVICE_ACCOUNT` | קובץ ה-JSON של service account מ-Firebase (Project settings ← Service accounts) |
| `AERODATABOX_KEY` | מפתח RapidAPI לתוכנית החינמית של AeroDataBox. בלעדיו רק התזכורות נשלחות |

ובנוסף `vapidKey` ב-`js/config.js` (Firebase ← Project settings ← Cloud Messaging ← Web Push certificates).

בדיקה: Actions ← Flight status and reminders ← Run workflow, לסמן את התיבה, ולכל טלפון שהפעיל התראות תגיע הודעת בדיקה.
